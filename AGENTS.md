# AGENTS.md

## Регламент работы с репозиторием

- При каждом коммите обновлять раздел «История изменений» в `SPEC.md`:
  добавить строку с датой и сутью изменений. Для строки текущего коммита
  в колонке hash ставить «—» (hash невозможно знать до коммита); следующим
  коммитом заменять «—» на фактический hash.
- Если коммит меняет поведение, описанное в разделах SPEC.md (API, UI,
  конфигурация и т.п.), синхронно править и соответствующие разделы.
- Пушить изменения только по явной просьбе пользователя.
